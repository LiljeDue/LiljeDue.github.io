A lexer is a program which identifies lexemes (e.g., keywords, identifiers, literals, etc.) which can be used for syntax analysis. These lexers are commonly generated by giving a set of regular expressions that specify the patterns to be extracted as lexemes.

These lexers are often implemented in a sequential or concurrent manner. We have already implemented a lexer generator which generates data-parallel lexers written in CUDA and Futhark, but we are not able to generate lexers written in ISPC.

[ISPC](https://ispc.github.io/) is a data-parallel, C-like language which focuses on generating efficient CPU code that utilizes SIMD instructions. The goal of this project will be to implement such a lexer.
